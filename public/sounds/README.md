# Sounds Directory

Adiciona ficheiros de áudio MP3 nesta pasta com os seguintes nomes:

- `correct.mp3` — Som de resposta correta (500ms, volume 0.6)
- `incorrect.mp3` — Som de resposta incorreta (400ms, volume 0.5)
- `combo.mp3` — Som de combo (600ms, volume 0.7)
- `victory.mp3` — Som de vitória/fim de batalha (1500ms, volume 0.8)
- `chest_open.mp3` — Som de abertura de baú (800ms, volume 0.7)
- `purchase.mp3` — Som de compra (700ms, volume 0.6)
- `coins.mp3` — Som de moedas (500ms, volume 0.5)
- `level_up.mp3` — Som de subida de nível (1200ms, volume 0.8)
- `guardian_voice.mp3` — Som de voz do Guardião (2000ms, volume 0.7)

## Recomendações
- Formato: MP3 32kbps ou 64kbps (melhor compatibilidade mobile)
- Resoluções: efeitos curtos (< 2seg), sem música de fundo
- Licensing: Deve ter licença Creative Commons ou ser próprio
- Fonte: FreeSound.com, Pixabay, Zapsplat (com licenças adequadas)

## Atribuições
Quando adicionar sons, documentar a licença em `AUDIO_LICENSES.md`
